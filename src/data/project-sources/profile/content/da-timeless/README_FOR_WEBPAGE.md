# Da Timeless

Python · PostgreSQL · dbt · FastAPI · asyncio · React · TypeScript · Cloudflare R2
<!-- SHARED:END -->

<!-- WEBPAGE:START -->
I built a data platform for competitive MTG Arena Timeless,
covering data collection, validation, storage, analysis,
Discord integration and web presentation.

The platform brings together tournament and league results
with community-submitted Metagame Challenge runs.

Incoming records pass through validation and review before
publication. PostgreSQL stores published facts. Separate source
evidence allows records to be traced and checked.

A shared Python backend provides reporting and administrative
tools for the React website and Discord bot. Analysis covers
event results, deck performance and leaderboards.

Source code is private.

# Manim Ecosystem

Python · Manim · Manim Slides · LaTeX
<!-- SHARED:END -->

<!-- WEBPAGE:START -->
Three complementary libraries for scientific presentations,
animated companions and physics explanations:

- BeAnim provides presentation components and shared styling.
- Digital Presenter adds animated companions and scripted dialogue.
- String Cosmo provides objects and animations for string theory
  and braneworld cosmology.

Each library keeps its own repository, documentation and examples.
Components can be combined within the same Manim presentation.
